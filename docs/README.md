# Project docs

Four project docs live in Claude Docs and need to be exported into this folder as Markdown. In each doc, open the menu under the doc's name, choose Export, then Markdown, and save the file under the name below.

| Doc | Save as |
| --- | --- |
| [WHM Requirements](https://claude.ai/artifact/GSUPnwH12SYFXNmabCQB2i) | `docs/requirements.md` |
| [WHM Prototype Plan](https://claude.ai/artifact/Nfs6VkeSqgZG9xckVUphPs) | `docs/prototype-plan.md` |
| [WHM Roadmap](https://claude.ai/artifact/FHQrJbt2DQdmtpWiHAoQ2Z) | `docs/roadmap.md` |
| [WHM Personas](https://claude.ai/artifact/HC3VUxnrg1zL4Ds8B46Y5L) | `docs/personas.md` |

Export again after any change to those docs, so Claude Code works from the current version. Diagrams in the docs come through as text placeholders. The architecture diagram's content is described in `prototype-plan.md` and in `CLAUDE.md`.

Already in this folder:

- `decisions.md`: dated decision log. It wins where it disagrees with an export.
- `data-contract.md`: the JSON structure shared by the pages, workflows and live fetch.
- `siteimprove-endpoints.md`: what is confirmed, inferred or unknown about each Siteimprove endpoint.
